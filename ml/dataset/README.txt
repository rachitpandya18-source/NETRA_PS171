NETRA Combined UI Detection Dataset v2

Combined existing NETRA Web UI dataset with 50 CVAT-reviewed government/public-service screenshots.
Old split preserved: 297 train, 22 val, 6 test. New CVAT split: 40 train, 10 val.
Final: 337 train, 32 val, 6 untouched test.
Class IDs preserved 0-9. The 50 CVAT annotations were reviewed in CVAT by the project team before export.
